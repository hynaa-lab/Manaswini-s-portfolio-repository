Risk-Informed Validation Framework for Java Maven Projects

Builds a Maven project, runs its unit tests and ranks every class as HIGH, MEDIUM or LOW validation priority. Metrics from JUnit/Surefire, JaCoCo, PMD, SpotBugs and CK feed Python ML models that estimate class-level defect risk. A MASON agent-based simulation, evaluated over 12 model-result records, 3 release transitions and 4 configurations, models validation activity. Results surface in a React dashboard on FastAPI.
